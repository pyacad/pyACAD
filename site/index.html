pyACAD

Python tools for Autodesk AutoCAD 2021 to 2026.

A folder with a script and an icon becomes a ribbon button and an AutoCAD command. No compiling, no restart.

Download v0.1.0 Your first button 5 min
1

Make a folder

MyTools.extension\
  MyTools.tab\
    Drafting.panel\
      Count.pushbutton\
        script.py
2

Write the script

from pyacad import ents, toast

n = ents.count()
toast.success('%d objects' % n)
3

Press Reload

It is a ribbon button, and an AutoCAD command too: type PYCOUNT, put it in a macro, or call (pyacad "PYCOUNT") from AutoLISP.
