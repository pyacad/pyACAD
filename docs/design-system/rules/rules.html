The slop test

Before shipping any surface, check it against the tells. If a screenshot could pass for a template demo, it fails. The goal is an interface a Windows user trusts instantly and stops noticing.

Banned tells

  • Gradients in text, fills or backgrounds. Anywhere.
  • Glassmorphism: blur, translucency, acrylic on content surfaces.
  • Tint-soup: accent-alpha washes as default backgrounds or borders.
  • Pill-soup: rounded chips carrying plain data that should be text.
  • Badge marketing: "Recommended" stickers, sparkle icons, emoji in UI.
  • Hero cards for what is simply a choice between two options.
  • Centered content in rows, lists or forms.
  • Hover-only affordances: controls invisible until pointed at.
  • Decorative motion: entrance animations, fades for their own sake.
  • Opacity as disabled: dimming a control that still responds. It stays clickable and its text drops below contrast.
  • Mouse-only controls: anything unreachable by Tab, or a field that swallows Tab and traps the user inside it.
  • A control per row: building one element for every item in a list. A list of thousands must virtualize, or it is a defect.
  • Blank waiting: an empty framed box where an empty state, a no-results state, or a busy state belongs.
  • Hand-drawn OS chrome: a custom titlebar imitating the real one.

What to do instead

  • Neutral grays and whitespace set the tone, but structure is BOLD: group frames (#A6A6A6) with straddling titles, not faint hard-to-see hairlines.
  • Affordances are visible: circled expander chevrons, a diagonal-dot resize grip on resizable windows, quiet-but-present scrollbars.
  • Accent in three places only: primary action, selection rail, focus ring.
  • Numbers are text: tabular, right-aligned, muted.
  • Native Windows affordances: checkbox, toggle, segmented, standard captions.
  • The default option is the recommendation; a caption explains why.
  • One signature moment per tool: the readout. Everything else whispers.
  • Sentence case, plain verbs, no em dashes; errors say the fix.
  • Motion only as state feedback, 120ms, ease-out.
  • Every control has rest, pressed, focused and disabled; a disabled control says why in a caption beside it.
  • White on the accent is not automatic: pick the foreground by luminance, because a light Windows accent makes white text unreadable.
  • Bulk work shows counted progress and can be cancelled, and lands as one undo step, not thousands.
  • Dialogs set their owner to the host window, close on Esc, and never let Enter trigger a destructive default.
  • Right-click is a shortcut, never the only route to a command.
