Use the real Windows titlebar. Every pyACAD window is a plain WPF window with system chrome; the drawing below is what Windows already gives us, shown here so the rules about title text and behavior have somewhere to live. Do not hand-draw a titlebar: a custom bar that imitates the OS is invisible work at best, and drifts from the OS at worst. Identity comes from the work, not the chrome. No accent dot, no gradient text, no pill buttons.

Modality and ownership. A dialog sets its owner to the AutoCAD main window handle. Without an owner it is not modal to the host, so it sinks behind AutoCAD and looks like a crash. It also stays out of the taskbar and opens centred on the owner.

Keyboard contract. Esc closes (the cancel button carries IsCancel), Enter commits the primary action (IsDefault) except where the primary action is destructive: a confirm that deletes must default to the safe choice, so Enter cannot destroy anything.
