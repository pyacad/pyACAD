Rules

1. Anything a user can operate must be reachable and operable from the keyboard. A control that only answers the mouse is unfinished, and one that traps Tab is a defect.
2. The hit target is at least 28px in its smallest dimension, and includes the label.
3. A custom control adopts the same selection language as the list: neutral wash plus a 3px accent rail, never a coloured fill for "chosen".
4. Validation is live. An error appears as the user types and clears the same way.
