Output (HTML)

The rich output window is a WebView2 page, so it is the one surface written in CSS rather than WPF. It is still the same design system: the page maps CSS custom properties onto the same Tokens, and a value that disagrees with the desktop side is drift, not licence.

Parity rules

Radius 4 everywhere, matching the desktop; 32px table rows; the scrollbar is the same 10px quiet thumb; body text 13, captions and secondary columns 12, mono 12.5. Numeric columns are tabular and right-aligned, but only actual numbers: do not right-align the last column because it is last. Motion is 120ms ease-out or nothing.

An element link selects the item in the model, so it is a control, not decoration: it must be a real focusable anchor, reachable by Tab, with a visible :focus-visible ring in the accent. A span that only answers a click is unusable by keyboard and invisible to a screen reader. Progress is the same 4px accent bar as the desktop.
