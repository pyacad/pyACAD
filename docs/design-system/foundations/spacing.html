Layout

Whitespace and single hairlines do the structuring; boxes only where containment earns its border (lists, inputs). Page padding has two values, chosen by what the window is for: 24px for prose and settings windows (alerts, confirms, ask-string), where the text needs room to read; 16px for data-dense windows (the layer dialogs, the output window, the console), where every pixel of padding is a row the user cannot see. Anything else is drift. One corner radius: 4px. No elevation stack: surfaces sit flat and are separated by hairlines, never by shadow. The single exception is a popup that floats over the window it belongs to (dropdown menu, context menu), which carries one soft shadow so its edge reads against the surface beneath. Nothing that is part of the page may cast one.
