The pyacad library is what your script talks to instead of the raw AutoCAD .NET API. It is a flat set of small modules, each covering one surface of the drawing or of pyACAD itself: the active document, the selection, entities, layers, blocks, xrefs, layouts, plotting, drawing health, AutoLISP, units, and then the dialogs, toasts, the output window, settings and Excel files. Almost everything is a plain function that takes and returns plain Python values.

This page is the complete public surface. If a name is not on this page, it is either private (it starts with an underscore) or it does not exist. Every signature below was taken from the source, and every pyacad.module.name in an example is checked against the library each time the site is built.

Importing pyacad

The package itself exports one name:

import pyacad

pyacad.__version__      # '0.1.0'
pyacad.doc              # AttributeError until something imports pyacad.doc

Everything useful lives in a submodule, and the house style is to import the submodules you need by name:

from pyacad import doc, ents, layers, forms, toast

That reads well at the call site (layers.freeze('A-*'), toast.success('Done')) and it matters here for a second reason: several functions share a name with a Python builtin (ents.set, ents.iter, xrefs.list), so from pyacad.ents import * would quietly replace set and iter in your script. Never star-import a pyacad module.

Underscore modules are off limits

pyacad._api, _atomic, _charts, _datafiles, _history, _log, _markdown, _repl, _util and _xlsx are internal. They change without notice and have no compatibility promise; _api loads the AutoCAD assemblies as a side effect of being imported. Everything they do that a script needs is exposed by a public module. The private modules at the foot of this page says what each one is, so you can recognise them in a traceback.

The modules at a glance

The last column says whether importing the module needs a live AutoCAD session with pyACAD loaded. The drawing modules import anywhere because they reach the AutoCAD API only inside each function, through pyacad._api; calling one of their API functions outside AutoCAD raises ImportError with a plain message. The four framework modules marked yes load the pyACAD runtime assembly at import time, so they import only inside AutoCAD (or AutoCAD Core Console under pyacad run).

Three badges appear on every function: Pure means plain Python with no AutoCAD and no pyACAD runtime, so it runs and unit-tests anywhere, including a dev-time CPython; Needs AutoCAD means it reads or changes the drawing, or talks to the pyACAD runtime (a window, a toast, the running command), so it only works inside AutoCAD; Blocks means it opens a modal window or a command-line prompt and your script waits until the user answers.

Conventions that cut across every module

The modules were written to one set of rules. Read these once and most of the individual entries below become predictable.

Objects are handles, not AutoCAD objects

Every entity, block reference and table the library hands you is identified by its handle: the hex string AutoCAD shows in LIST, such as '2F3A'. Handles survive saving and reopening, so you can store them, write them to Excel and match them up later. Functions that read return plain dicts, lists and strings, never an AutoCAD object that would go stale once its transaction closes. The only functions that hand you raw .NET objects are doc.active(), doc.database(), doc.editor(), doc.transaction() and doc.lock(), which exist for the moment you need the API directly.

A handle argument may be upper or lower case and may carry a 0x prefix (ents.normalize_handle cleans it). An argument that takes "one or many" handles or names also accepts a single string.

Points are tuples, angles are radians

Points come back as (x, y, z) tuples of floats. Points you pass in may be (x, y) or (x, y, z); a 2D point gets z = 0.0. Angles, such as a block reference's rotation in ents.get or the rotation you give blocks.insert, are in radians, as AutoCAD stores them. The one exception is blocks.export_rows, which writes degrees for people to read in Excel.

One call, one transaction

Each function opens its own transaction (through doc.transaction()), commits it when it finishes and aborts it if anything raises. A failed call therefore leaves the drawing exactly as it was. The cost is that calling ents.set a thousand times opens a thousand transactions; where a tool naturally works on many objects there is a batch function that does them all in one (ents.lengths, ents.delete, blocks.snapshots, blocks.apply_changes, audit.erase, layers.merge).

Command context and document locks

A ribbon click, a keyboard chord and a typed command name all run your script as an AutoCAD command, so the document is already locked and the whole run is one undo step. A (pyacad ...) call from AutoLISP runs it in document context, inside whatever command or expression called it. Code that runs later, outside any command, is not: a hook, a dock pane's button handler, a modeless window's callback. Wrap anything that changes the drawing there in with doc.lock():. Reading usually works without a lock, but taking one costs nothing.

Two kinds of wildcard

Name patterns in layers (and the block name in blocks.references) use pyacad's own matcher: * is any run of characters, ? is one character, matching ignores case and covers the whole name, and you may pass a list of patterns. Nothing else is special, so # and @ are literal. sel.get(layer=...) is different: it goes straight into an AutoCAD selection filter, so it uses AutoCAD's own wildcard syntax (the WCMATCH rules, where #, @, ~ and commas mean something).

Naming a space

Functions that take a space argument read it the same way (ents.resolve_space): None, '' or 'model' (any case) is model space, 'BLOCK:Door' is the definition of block Door, and anything else is a paper space layout's name. Watch the default: in ents, space=None means model space only; in blocks.references and blocks.counts, space=None means model space and every layout.

Progress and cancel callbacks

Long-running functions take two optional callables, progress and cancelled. Every doc.STEP items (200), starting with the first, the function calls progress(index, total) and then cancelled(); when cancelled() returns true it stops. Most stop where they are and return what they have so far (and commit it, for the ones that write); layers.merge instead raises RuntimeError and rolls everything back. The cookbook shows how to wire these to a progress window.

doc: the active drawing

Every other drawing module reaches the drawing through this one, and doc.transaction() is the single way into the database. The module imports anywhere; its AutoCAD functions import the API when called. Everything here works in Core Console too (none of it needs the AutoCAD UI assembly). The last four functions are pure helpers the other modules share, and you are welcome to use them.

doc.active

doc.active()

Needs AutoCAD The active Document (AutoCAD's DocumentManager.MdiActiveDocument). Raises RuntimeError('No drawing is open.') when there is none, which makes it the natural first line of a tool that must have a drawing.

from pyacad import doc

document = doc.active()
print(document.Name)

doc.database

doc.database()

Needs AutoCAD The active drawing's Database. Raises RuntimeError like doc.active().

db = doc.database()

doc.editor()

Needs AutoCAD The active drawing's Editor, for prompts and messages the library does not wrap.

doc.editor().WriteMessage('\nHello from pyACAD\n')

doc.path

doc.path()

Needs AutoCAD The drawing's full path as a string, or the literal 'untitled' when it has never been saved. Compare against 'untitled', not against None.

if doc.path() == 'untitled':
    toast.warning('Save the drawing first')

doc.is_saved

doc.is_saved()

Needs AutoCAD True when the drawing has a file and no unsaved changes (the DBMOD system variable is 0). Always False for an untitled drawing.

if not doc.is_saved():
    forms.alert('Save your changes before running a batch plot.')

doc.is_read_only

doc.is_read_only()

Needs AutoCAD True when the drawing was opened read-only.

if doc.is_read_only():
    toast.error('This drawing is read-only')

doc.transaction

doc.transaction()

Needs AutoCAD A context manager over one database transaction. with hands you the AutoCAD Transaction; it commits when the block ends normally and aborts when the block raises (the exception still propagates), then disposes it either way. Use it when you need the raw API inside one transaction; the rest of the library calls it for you.

from pyacad import doc

db = doc.database()          # loads the AutoCAD assemblies on first use
from Autodesk.AutoCAD.DatabaseServices import OpenMode

with doc.transaction() as tr:
    table = tr.GetObject(db.LayerTableId, OpenMode.ForRead)
    print(table.Has('A-WALL'))
Raw API types

The Autodesk.AutoCAD namespaces import once the assemblies are loaded, and the first pyacad call that touches the drawing loads them. That is why the example calls doc.database() before the from Autodesk... line.

doc.lock

doc.lock()

Needs AutoCAD A context manager that locks the active document and unlocks it on exit. Commands are already locked; you need this in code that runs outside a command: hooks, dock pane handlers, modeless window callbacks. It does not start a transaction.

def on_click(sender, args):          # a dock pane button
    with doc.lock():
        layers.freeze('Z-*')

doc.save

doc.save()

Needs AutoCAD Saves the drawing to its own path in the current DWG format, taking a document lock itself, and returns the path. Raises RuntimeError when the drawing has never been saved (there is no path to save to) or is read-only.

saved_to = doc.save()
toast.success('Saved', saved_to)

doc.units

doc.units()

Needs AutoCAD The drawing's insertion units (INSUNITS) as AutoCAD's enum name, such as 'Millimeters', 'Inches' or 'Undefined'. These names are exactly what the units module takes.

print(doc.units())     # 'Millimeters'

doc.open_documents

doc.open_documents()

Needs AutoCAD A list with one entry per open drawing: the full path for saved drawings, the document name (such as 'Drawing1.dwg') for untitled ones.

for name in doc.open_documents():
    print(name)

doc.send_command

doc.send_command(text)

Needs AutoCAD Queues text plus a newline on the active drawing's command line. It does not run now: it runs after your script returns, so you get nothing back and the next line of your script runs before it. Prefix command names with _. so they work in any language and are not redefined.

doc.send_command('_.ZOOM _E')

doc.sysvar

doc.sysvar(name)

Needs AutoCAD A system variable's value, as AutoCAD returns it (an int, float, string or point object). Wrap it in int() or str() when you compare it, as the library does.

if int(doc.sysvar('PSLTSCALE')) != 1:
    toast.warning('PSLTSCALE is not 1')

doc.set_sysvar

doc.set_sysvar(name, value)

Needs AutoCAD Sets a system variable. Booleans go in as 1 or 0. Integers are tried as 16-bit first (most integer variables are) and then as 32-bit, floats go in as doubles, anything else as it is. AutoCAD raises its own exception for an unknown or read-only variable.

doc.set_sysvar('LTSCALE', 1.0)
doc.set_sysvar('PSLTSCALE', True)
doc.set_sysvar('CLAYER', 'A-WALL')

doc.as_point

doc.as_point(value)

Pure (x, y) or (x, y, z) as a tuple of three floats; a 2D point gets z = 0.0. Raises ValueError for anything else.

doc.as_point((10, 20))        # (10.0, 20.0, 0.0)

doc.as_names

doc.as_names(value)

Pure One name or an iterable of names as a list of strings; None gives []. This is why "one or many" arguments accept a bare string.

doc.as_names('A-WALL')            # ['A-WALL']
doc.as_names(('A-WALL', 'A-DOOR'))

doc.step

doc.step(index, total, progress=None, cancelled=None)

Pure The progress and cancel hook every batch function uses. On every STEPth index (0, 200, 400, ...) it calls progress(index, total) when given, then returns True when cancelled is given and returns true. On other indices it returns False without calling anything. Use it in your own loops to behave like the library.

for index, handle in enumerate(handles):
    if doc.step(index, len(handles), report, user_cancelled):
        break

doc.STEP

doc.STEP = 200

Pure How many items pass between progress reports and cancel checks in every batch function.

sel: selection

The pickfirst set (what is selected when your tool starts), interactive picks on the command line, and filtered select-all. Everything is in handles. build_filter and value_kind are pure; the rest import the API when called. The pick_* prompts need an interactive editor, so under Core Console they come back as None or [].

sel.current

sel.current()

Needs AutoCAD Handles of the objects that were selected when the command started (the pickfirst set), or []. pyACAD's commands accept a pickfirst set, so selecting first and then clicking a button works.

from pyacad import sel, toast

picked = sel.current()
if not picked:
    toast.info('Select something first')

sel.set_current

sel.set_current(handles)

Needs AutoCAD Makes these handles the pickfirst set, so they show as selected (grips) when your script ends. One handle or a list. Raises ValueError for a handle that does not exist.

sel.set_current(sel.get(type='CIRCLE'))

sel.clear

sel.clear()

Needs AutoCAD Empties the pickfirst set.

sel.clear()

sel.pick_one

sel.pick_one(prompt='Select an object: ')

Needs AutoCAD Blocks Prompts on the command line for one object and returns its handle, or None when the user presses Esc or picks nothing.

handle = sel.pick_one('Select a block: ')
if handle and ents.type_of(handle) == 'INSERT':
    print(blocks.attributes(handle))

sel.pick_many

sel.pick_many(prompt='Select objects: ')

Needs AutoCAD Blocks Prompts for a selection (window, crossing, any method) and returns a list of handles, [] on cancel.

handles = sel.pick_many('Select lines to measure: ')

sel.pick_point

sel.pick_point(prompt='Pick a point: ')

Needs AutoCAD Blocks Prompts for a point (object snaps work) and returns (x, y, z) in world coordinates, or None on cancel.

point = sel.pick_point('Insertion point: ')
if point is not None:
    blocks.insert('NORTH', point)

sel.get

sel.get(type=None, layer=None, space=None, **more)

Needs AutoCAD Handles of every entity in the drawing that passes the filter, using AutoCAD's select-all with a selection filter (see sel.build_filter for the arguments). With no arguments it returns every entity in model space and all layouts. Entities inside block definitions are not included, because select-all never sees them.

walls = sel.get(type='LWPOLYLINE', layer='A-WALL*')
texts = sel.get(type=['TEXT', 'MTEXT'], space='model')
red = sel.get(c62=1)                   # colour index 1 set on the entity

sel.build_filter

sel.build_filter(type=None, layer=None, space=None, **more)

Pure The (code, value) pairs sel.get turns into a selection filter. type is one DXF name or a list (any case, joined with commas as AutoCAD expects); layer is a layer name with AutoCAD wildcards; space is a layout name, with 'model' (any case) meaning model space. Any other DXF group code goes in as a keyword c<code>=value, such as c62=1 for colour 1 or c40=2.5 for a radius; the value is converted to what that code takes (see sel.value_kind) and extra pairs are sorted by code. Raises ValueError for a keyword that is not shaped like c62.

sel.build_filter(type=['line', 'arc'], layer='M-*', c62=3)
# [(0, 'LINE,ARC'), (8, 'M-*'), (62, 3)]

sel.value_kind

sel.value_kind(code)

Pure What a DXF group code takes in a filter: 'int16', 'int32', 'double', 'point' or 'text' (anything not in a numeric or point range).

sel.value_kind(62)    # 'int16'
sel.value_kind(40)    # 'double'
sel.value_kind(8)     # 'text'

ents: entities by handle

Iterate a space, take a snapshot of an entity as a plain dict, change a few common properties, delete, and measure. ents.get returns a dict, so a script never holds an AutoCAD object past its transaction. resolve_space, normalize_handle, check_props and length_by_layer are pure. Two functions here are named like builtins, iter and set: always call them as ents.iter and ents.set.

ents.iter

ents.iter(space=None)

Needs AutoCAD A generator over the handle of every entity in model space (the default), a layout (its name) or a block definition ('BLOCK:Name'). The handles are read in one transaction before the first one is yielded, so changing the drawing while you loop is safe. Raises ValueError for an unknown layout or block.

from pyacad import ents

for handle in ents.iter():
    print(handle, ents.type_of(handle))

for handle in ents.iter('BLOCK:Door'):
    pass        # the entities that make up the Door definition

ents.get

ents.get(handle)

Needs AutoCAD A snapshot of one entity as a plain dict. Every entity carries handle, type (the DXF name), layer, color (the colour index: 256 is ByLayer, 0 ByBlock), linetype, lineweight (an int, see ents.LINEWEIGHTS), visible and space ('Model', a layout name, or 'BLOCK:Name'). Some types add geometry:

TypeExtra keys
LINEstart, end
CIRCLEcenter, radius
ARCcenter, radius, start_angle, end_angle (radians)
LWPOLYLINEpoints (a list of (x, y)), closed
TEXTtext, height, position
MTEXTtext (the raw contents, formatting codes included), height, position
INSERTname (a dynamic block's real name, not *U12), position, rotation (radians), scale (x, y, z), attributes {tag: text}

Raises ValueError when no object has that handle.

snap = ents.get('2F3A')
if snap['type'] == 'LINE':
    print(snap['start'], snap['end'])

ents.set

ents.set(handle, **props)

Needs AutoCAD Changes properties of one entity. Any entity takes layer, color (an int 0 to 256), linetype, lineweight (one of ents.LINEWEIGHTS) and visible; TEXT and MTEXT also take text and height; INSERT takes attributes (a dict of tag to text, matched to the tags exactly as the drawing spells them). Everything is validated by ents.check_props before anything changes, and the layer and linetype must exist ('ByLayer' and 'ByBlock' are always allowed), else ValueError. Returns None. An entity on a locked layer raises AutoCAD's eOnLockedLayer.

ents.set('2F3A', layer='A-WALL', color=256)
ents.set('2F40', text='LEVEL 2', height=3.5)
ents.set('2F41', attributes={'ROOM_NO': '2.14'})

ents.delete

ents.delete(handles, progress=None, cancelled=None)

Needs AutoCAD Erases the entities (one handle or a list) in one transaction and returns how many were erased. A handle that does not exist raises ValueError and nothing is erased; an entity on a locked layer raises AutoCAD's exception and nothing is erased. Stopping through cancelled keeps what was erased so far. For a forgiving delete that skips locked layers and missing handles, use audit.erase.

erased = ents.delete(sel.get(type='POINT'))

ents.count

ents.count(space=None)

Needs AutoCAD How many entities a space holds (model space by default; a layout name or 'BLOCK:Name' otherwise).

print(ents.count(), 'in model space')

ents.bounds

ents.bounds(handle)

Needs AutoCAD The entity's extents as ((minx, miny, minz), (maxx, maxy, maxz)). AutoCAD raises its own exception for an entity with no extents (an empty text, a ray).

low, high = ents.bounds(handle)
width = high[0] - low[0]

ents.type_of

ents.type_of(handle)

Needs AutoCAD The entity's DXF type name, such as 'LINE', 'LWPOLYLINE' or 'INSERT', without opening a transaction. Raises ValueError for an unknown handle.

if ents.type_of(handle) == 'INSERT':
    print(blocks.attributes(handle))

ents.length_of

ents.length_of(handle)

Needs AutoCAD The length along a curve in drawing units: lines, arcs, circles (the circumference), polylines of every kind, splines and ellipses. Raises ValueError for anything without a length.

print('%.1f' % ents.length_of(handle))

ents.lengths

ents.lengths(handles, types=LENGTH_TYPES, progress=None, cancelled=None)

Needs AutoCAD Measures many curves in one transaction. Returns a list of {'handle', 'type', 'layer', 'length'} for each handle whose DXF type is in types (by default ents.LENGTH_TYPES: lines, arcs, both kinds of polyline and splines). Other entities and handles that no longer exist are left out silently; a curve AutoCAD cannot measure gets length None. Feed the result to ents.length_by_layer for totals.

rows = ents.lengths(sel.get(layer='M-DUCT*'))
total = sum(r['length'] for r in rows if r['length'] is not None)

ents.length_by_layer

ents.length_by_layer(snapshots)

Pure Totals per layer from dicts that carry at least 'layer' and 'length' (what ents.lengths returns): a list of {'layer', 'count', 'length'} sorted by layer name ignoring case. A dict whose length is None is left out of both the count and the total.

ents.length_by_layer([{'layer': 'A', 'length': 2.0}, {'layer': 'A', 'length': 3.0}])
# [{'layer': 'A', 'count': 2, 'length': 5.0}]

ents.resolve_space

ents.resolve_space(text)

Pure How a space argument is read: ('model', 'Model') for None, '' or 'model' in any case; ('block', name) for 'BLOCK:name'; ('layout', text) for anything else. Raises ValueError for 'BLOCK:' with no name.

ents.resolve_space('block:Door')    # ('block', 'Door')
ents.resolve_space('A1 Plan')       # ('layout', 'A1 Plan')

ents.normalize_handle

ents.normalize_handle(handle)

Pure A handle as uppercase hex text, with surrounding spaces and a 0x prefix removed. Raises ValueError when the text is not hex. Use it before comparing handles that came from a spreadsheet or a file.

ents.normalize_handle(' 0x2f3a ')    # '2F3A'

ents.check_props

ents.check_props(type_name, props)

Pure The validation ents.set runs: raises ValueError when a key is not allowed for that DXF type, when color is not an int from 0 to 256, when lineweight is not in ents.LINEWEIGHTS, when height is not above zero, or when attributes is not a dict. Returns None otherwise. Handy for checking user input before a batch.

ents.check_props('LINE', {'color': 1})       # fine
ents.check_props('LINE', {'text': 'x'})      # ValueError: LINE cannot set 'text'

ents.LINEWEIGHTS

ents.LINEWEIGHTS = ( -3, -2, -1, 0, 5, 9, 13, 15, 18, 20, 25, 30, 35, 40, 50, 53, 60, 70, 80, 90, 100, 106, 120, 140, 158, 200, 211 )

Pure The lineweights ents.set accepts, in hundredths of a millimetre: -3 is Default, -2 ByBlock, -1 ByLayer, and the rest are AutoCAD's standard weights from 0 to 2.11 mm. The same numbers come back in ents.get and layers.get.

ents.LENGTH_TYPES

ents.LENGTH_TYPES = ('LINE', 'ARC', 'LWPOLYLINE', 'POLYLINE', 'SPLINE')

Pure The DXF types ents.lengths measures by default. POLYLINE covers both the old 2D polyline and the 3D polyline.

layers: layers and layer standards

Read, create, rename, delete and merge layers; freeze, thaw, turn off and on, lock and unlock by pattern; isolate; and save and restore layer states. Pattern arguments take * and ?, ignore case, and may be a list of patterns. The freeze-style functions return how many layers actually changed and regenerate the drawing. The second half of the module is pure: matching, a filter box, and the engine behind a layer-standard mapping (a CSV of old name to new name).

layers.names

layers.names()

Needs AutoCAD Every layer name in the drawing, in layer table order (xref layers included, as Xref|Layer).

from pyacad import layers

for name in layers.names():
    print(name)

layers.current

layers.current()

Needs AutoCAD The current layer's name (CLAYER).

print(layers.current())

layers.set_current

layers.set_current(name)

Needs AutoCAD Makes the named layer current, thawing it and turning it on first so AutoCAD accepts it. Raises ValueError when there is no such layer.

layers.set_current('A-ANNO')

layers.exists

layers.exists(name)

Needs AutoCAD True when the drawing has a layer of that name (AutoCAD compares layer names ignoring case).

if not layers.exists('A-ANNO'):
    layers.create('A-ANNO', color=2)

layers.get

layers.get(name)

Needs AutoCAD One layer as a dict: name, color (the colour index), linetype (its name), lineweight (an int, see ents.LINEWEIGHTS), is_off, is_frozen, is_locked, is_plottable. Raises ValueError for an unknown layer.

state = layers.get('A-WALL')
if state['is_frozen']:
    layers.thaw('A-WALL')

layers.create

layers.create(name, color=7, linetype='Continuous')

Needs AutoCAD Adds a layer and returns its name. color is a colour index from 1 to 255 (not 0 or 256, which mean ByBlock and ByLayer); linetype must already be loaded in the drawing. Raises ValueError when the layer exists, the name is not a valid symbol name, the colour is out of range or the linetype is missing.

layers.create('M-DUCT-SUPPLY', color=4, linetype='Continuous')

layers.rename

layers.rename(old, new)

Needs AutoCAD Renames a layer. Raises ValueError for layer 0 and Defpoints, an unknown old name, an invalid new name, or a new name another layer already has. A change of case only is allowed.

layers.rename('WALLS', 'A-WALL')

layers.delete

layers.delete(name)

Needs AutoCAD Erases a layer. Raises ValueError when it is layer 0 or Defpoints, the current layer, an xref layer, or still in use (AutoCAD's purge check says something references it). To empty a layer into another one first, use layers.merge.

try:
    layers.delete('OLD-TEMP')
except ValueError as error:
    toast.warning('Not deleted', str(error))

layers.merge

layers.merge(sources, target, progress=None, cancelled=None)

Needs AutoCAD Moves every entity on the source layers (one name or a list) to target, then deletes the sources, all in one transaction, and returns how many objects moved. It covers model space, every layout and every block definition in this drawing (not xrefs), including the attributes on block references, and it moves entities on locked layers too. If a source is the current layer, the target becomes current. A source equal to the target is ignored. Raises ValueError for an unknown layer or a source that cannot be deleted afterwards; when cancelled fires it raises RuntimeError('Merge cancelled; nothing was changed.') and rolls everything back.

moved = layers.merge(['WALL', 'WALLS', 'Wall-old'], 'A-WALL')

lisp: AutoLISP from Python

Call a LISP function, queue an expression, and read the arguments a (pyacad ...) call passed in. call goes through AutoCAD's acedInvoke, which reaches only functions LISP has exposed: commands defined as C:NAME and functions registered with (vl-acad-defun 'name). Arbitrary expressions cannot be evaluated synchronously from .NET, so evaluate queues one on the command line instead. Python functions cannot be registered as LISP functions; a script is reachable from LISP as (pyacad "PYNAME" args...), which hands it the arguments and returns its __result__ (see the Commands page). encode and decode are pure.

lisp.call

lisp.call(function, *args)

Needs AutoCAD Calls an exposed LISP function by name with Python arguments (encoded by lisp.encode) and returns its result as Python values: a single value bare, several as a list, nil as None, T as True, points as tuples, entity names as handles. Returns None when the function returns nothing. AutoCAD raises its own exception when the function is not exposed.

# LISP side, loaded at startup:
#   (defun pa-scale (sheet) (if (= sheet "A1") 50 100))
#   (vl-acad-defun 'pa-scale)
factor = lisp.call('pa-scale', 'A1')     # 50

lisp.evaluate

lisp.evaluate(expression)

Needs AutoCAD Queues a LISP expression on the command line (wrapping it in parentheses when you left them off). It runs after your script returns, so this always returns None.

lisp.args

lisp.args()

Needs AutoCAD The arguments of the (pyacad "PYNAME" args...) call, or of the PYACAD command line, that ran this script, as a list; [] when it got none. The same as script.get_args() and the __args__ global. From LISP, strings arrive as str, integers as int, reals as float, nil as None and T as True; from the PYACAD command line every argument is a string.

lisp.encode

lisp.encode(value)

Pure A Python value as (type code, value) pairs: None and False are nil, True is T, strings are text, ints are 32-bit integers (reals when they do not fit), floats are reals, lists and tuples are lists, and a dict is a list of (key value) pairs. Anything else becomes its str().

Pure (type code, value) pairs back into Python values: a list with one item per top-level LISP value. Lists nest, a dotted pair closes like a list, nil is None, T is True.

When the WebView2 runtime is missing it falls back to plain text, and under pyacad run everything goes to the transcript; your script never needs to care. table_html and format_table are pure, so the module imports anywhere.

script: the running command

What the running command is (its script, folder, title, arguments), the pyACAD session (toggle state, shared variables, theme, Reload), per-tool settings and data files, a logger, and a few Windows conveniences. It needs only the pyACAD runtime, never the AutoCAD API, so every function works in a hook or a dock pane as well as a button.

"The running command" is the last one that ran

The runtime records the command's identity when a button or command starts and keeps answering with it until the next one starts. A hook, startup.py, a smartbutton's ribbon-build run and a dock pane's script.py never set it, so inside them get_command_path, get_config, store_data and friends answer for whichever button the user clicked last. In those places use pyacad.settings with a tool key you choose. Code that runs after a button's script.py returns (a modeless window's handlers) should capture the identity first with script.bind().

settings: per-tool settings files

One JSON file per tool key under %APPDATA%\pyACAD\settings. Pure standard library with no AutoCAD and no runtime, so it works in any engine, in hooks and panes, and outside AutoCAD. script.get_config is built on it with the running tool's key; use this module directly when you want a key you choose, which is the only reliable choice in a hook, a dock pane or startup.py, and the way two tools share settings.

settings.load

settings.load(tool, defaults)

Pure The tool's saved values merged over defaults (settings.merge). A missing, unreadable or non-object file gives a fresh copy of the defaults; it never raises.

from pyacad import settings

cfg = settings.load('save_log', {'on': False, 'folder': ''})

settings.save

settings.save(tool, values)

Pure Writes values as the tool's settings file (sorted, indented JSON), creating the folder when needed. The write is atomic: a crash leaves the old file intact. values must be JSON-serialisable.

settings.save('save_log', {'on': True, 'folder': r'C:\Logs'})

settings.merge

settings.merge(defaults, stored)

Pure defaults overlaid with stored: only keys in defaults survive, so stale keys from an older version of a tool never leak back.

settings.merge({'a': 1, 'b': 2}, {'b': 3, 'old': 9})    # {'a': 1, 'b': 3}

settings.path_for

settings.path_for(tool)

Pure The settings file path for a tool key: %APPDATA%\pyACAD\settings\<tool>.json.

print(settings.path_for('save_log'))

xl: Excel workbooks

Reads and writes .xlsx files in pure Python, with no Excel and no third-party package, so it runs the same under IronPython and CPython, inside or outside AutoCAD. It writes a minimal valid workbook (inline strings, a bold header row, approximate column widths) and reads both its own files and workbooks Excel saved, shared strings included. Formulas, styles and charts are not its business.

xl.write

xl.write(path, rows, headers=None, sheet='Sheet1')

Pure Writes rows (lists of str, int, float, bool or None) to the sheet sheet of the workbook at path, with headers as a bold first row when given. Creates the folder when needed. If the file already holds a workbook, the named sheet is replaced in place (or added at the end) and the other sheets are kept, but only as values: they lose their formatting, a bold header row included, and their ints come back as floats. The file is written to a temporary file first and moved into place, so a failure leaves the old workbook intact. A file open in Excel raises IOError or OSError.

from pyacad import xl

xl.write(r'C:\Out\blocks.xlsx', [['DOOR', 12], ['WINDOW', 30]], headers=['Block', 'Count'])

xl.read

xl.read(path, sheet=None)

Pure The rows of the named sheet, or the first sheet when sheet is None. Numbers come back as float, booleans as True or False, everything else as str. A row is as long as its last used column, with gaps as ''; blank rows come back as [], so row positions match the sheet. Raises ValueError for a missing sheet.

rows = xl.read(path)
headers, body = rows[0], rows[1:]

xl.sheets

xl.sheets(path)

Pure The workbook's sheet names, in order.

if 'Blocks' in xl.sheets(path):
    rows = xl.read(path, sheet='Blocks')
