# Screenshots the tools guide is waiting for

Save each as `docs/tools/_assets/shots/<name>.png` (PNG, about 1200 px wide, light AutoCAD theme) and re-run `python tools/build_tools_site.py`. A page shows a labelled placeholder until its file exists.

## Settings (pyACAD)

- [ ] `settings-window.png`: The pyACAD settings window: Appearance, Shortcuts, extension folders, Engines, the AI assistant and Updates, with Save and Cancel and the version line at the bottom.

## Shortcuts (pyACAD)

- [ ] `shortcuts-editor.png`: The Shortcuts and Aliases window: tools grouped under their panel names, a chord being recorded into one row, an alias typed into another, and a conflict flagged.

## Console (pyACAD)

- [ ] `console-window.png`: The pyACAD Console: a short script in the lower pane, its output and the echoed value in the pane above, and the Run button.

## Blocks to Excel (Data)

- [ ] `blocks-to-excel-workbook.png`: A workbook from Blocks to Excel open in Excel: the fixed columns, then one column per attribute tag.

## Excel to Blocks (Data)

- [ ] `excel-to-blocks-confirm.png`: The question before anything is written: how many block references, attribute values and layer changes.

## Block Schedule (Data)

- [ ] `block-schedule-table.png`: A block schedule placed as a table titled Block Schedule, counted by block name and layer, with the Total row.
- [ ] `block-schedule-options.png`: The two quick choices: count by block name or by name and layer, then a table or a workbook.

## Find and Replace Attributes (Data)

- [ ] `find-replace-attributes-tag.png`: Choosing which attribute to replace in: Every tag, or one of the tags the chosen blocks carry.

## Layer Manager (Layers)

- [ ] `layer-manager-palette.png`: The Layer Manager palette docked at the side: the filter box, the layer list with its On, Frozen, Locked and Color columns, the action buttons and the status line.
- [ ] `layer-manager-merge.png`: Merge into...: the prompt for the target layer, with three layers selected.

## Layer Mapper (Layers)

- [ ] `layer-mapper-checklist.png`: The Layer Mapper checklist: renames, merges and creates, each with a tick box, and the layers that will be left alone named above.

## Layer Snapshot (Layers)

- [ ] `layer-snapshot-restore.png`: Restoring a layer state: the saved states for this drawing, newest first, with their time and layer count.

## Xref Manager (Xrefs)

- [ ] `xref-manager-list.png`: The Xref Manager list: each xref with its status and saved path, two of them ticked.
- [ ] `xref-manager-actions.png`: The action choice: Reload, Unload, Detach or Bind for the ticked xrefs.

## Xref Repath (Xrefs)

- [ ] `xref-repath-preview.png`: The repath preview: each change with its from and to path, then the xrefs left alone and why.

## Drawing Cleanup (Cleanup)

- [ ] `drawing-cleanup-checklist.png`: The Drawing Cleanup checklist with the default steps ticked.
- [ ] `drawing-cleanup-report.png`: The report after a run: one line per step, with the Copy button.

## Font and Proxy Report (Cleanup)

- [ ] `font-proxy-report.png`: The Font and Proxy Report: proxies grouped by class and application, then the text styles with a missing font.

## Batch Plot (Output)

- [ ] `batch-plot-layouts.png`: Batch Plot's layout list, every layout ticked, in tab order.
- [ ] `batch-plot-naming.png`: The naming choice, shown as the file names the first layout would get.

## Layout Manager (Output)

- [ ] `layout-manager-actions.png`: Layout Manager's first window: the five actions.
- [ ] `layout-manager-page-setup.png`: Apply page setup: the layouts to apply the chosen page setup to, all ticked.

## Length Takeoff (Takeoff)

- [ ] `length-takeoff-window.png`: Length Takeoff's totals per layer, with Export to Excel, Copy and Close.

## Tag Audit (Takeoff)

- [ ] `tag-audit-summary.png`: Tag Audit's summary: the duplicate values with their counts, then the blanks and the blocks without the attribute, with Select them, Export to Excel, Copy report and Close.

## Ask AI (AI (beta))

- [ ] `ask-ai-panel.png`: The Ask AI palette: a request, the model's reply with its files, and the Create tool card above the message box.

## AI Settings (AI (beta))

- [ ] `ai-settings-section.png`: The AI assistant section of Settings: provider, base URL, model, the API key with Test, and the longest answer.
