Two checks for building services drawings. Length Takeoff totals run lengths per layer, so a duct, pipe or cable layer reads as one figure. Tag Audit checks one attribute across your blocks and finds the values used twice, the blanks and the blocks that lack it. Both work on what you selected first, or on the whole drawing when nothing is selected, and both can hand the result to Excel.

What it does

Measures every line, arc, polyline (lightweight, old-style 2D and 3D) and spline in the selection, adds the lengths up per layer, and shows the totals in the drawing's units. With nothing selected it measures everything in model space. Other objects in the selection (circles, text, blocks) are passed over.

The window reads like this, layers sorted by name:

Model space: 312.48 m in 57 objects on 4 layers.

M-DUCT-SUPPLY    148.20 m  (21)
M-DUCT-RETURN    96.75 m  (14)
P-PIPE-CW    52.03 m  (17)
P-PIPE-HW    15.50 m  (5)

The number in brackets is how many objects make up that total. The window lists the first 20 layers; the export and the copy carry all of them.

How to use it

  1. Select the objects to measure, or select nothing to measure all of model space. A window or a crossing over one floor, or a Quick Select by layer, both work.
  2. Click Length Takeoff, or type PYLENGTHTAKEOFF.
  3. Read the totals. Then pick Export to Excel, Copy or Close.
  4. Export to Excel asks where to save, suggesting <drawing> - Length Takeoff.xlsx beside the drawing. An existing file of that name is replaced, not added to.
  5. Copy puts the same table on the clipboard, tab separated, ready to paste into Excel or an estimate.

The table

The Excel sheet is called Takeoff. The clipboard copy has the same columns:

ColumnHolds
LayerThe layer name. The last row is Total.
ObjectsHow many objects were measured on that layer.
Length (unit)The total as a number in drawing units, rounded to six decimals, so Excel can add it up. The header carries the unit, such as Length (mm), or just Length when the drawing's units are undefined.
LengthThe same total as text, as the window shows it.

Units

Lengths are read in drawing units and labelled from the drawing's insertion units (INSUNITS). Inches and feet show as feet and inches, such as 152'-3.50"; metric and the other units as a number and a short label, such as 45.20 m, always to two decimal places. A drawing whose units are undefined shows bare numbers. Nothing is converted: if a drawing is drawn in millimetres but INSUNITS says metres, the label is wrong and the figures are not.

Limitations

  • With nothing selected only model space is measured, even when you are on a layout tab.
  • Objects inside blocks and xrefs are not measured: a run drawn as a block counts as nothing. Explode it, or measure in the source drawing.
  • Circles and ellipses are not counted.
  • Lengths are true lengths along the object, in 3D. A line or 3D polyline that rises measures its sloped length, not its length in plan.
  • Grouping is by layer only, not by colour, linetype or size. Keep each system on its own layer to get one figure per system.
  • An object AutoCAD cannot measure is left out of the totals, and a toast says how many there were.

Other uses

  • Cable tray, conduit or sprinkler main lengths for a quick quantity before the proper takeoff.
  • Perimeter of walls drawn as polylines on their own layer.
  • A check that a layer you think is empty really holds nothing measurable, or how many stray objects sit on it.

What it does

Reads one attribute from every block reference in the selection, or with nothing selected, every block reference in model space and every layout. It reports three things:

  • Duplicates: values two or more blocks share. Values are compared trimmed and ignoring case, so AHU-1 and ahu-1 are the same tag.
  • Blanks: blocks that have the attribute but no value in it (or only spaces).
  • Missing: blocks that do not have that attribute at all.

If there is nothing to report, a toast says "Every TAG is filled in and unique" and the tool ends.

How to use it

  1. Select the blocks to check, or select nothing to check the whole drawing.
  2. Click Tag Audit, or type PYTAGAUDIT.
  3. Pick the attribute to audit. The list holds every attribute tag those blocks carry, in the order the drawing holds them. TAG is picked to start with when one of them has it.
  4. Read the summary. It names up to eight duplicate values with how many blocks share each (AHU-1 x2), then how many blocks have a blank value and how many lack the attribute, each broken down by block name.
  5. Pick what next:
    • Select them makes the blocks with a duplicate or blank value the current selection, so you can find and fix them. Blocks that lack the attribute are not selected, since they are usually other kinds of block. This choice is offered only when there are duplicates or blanks.
    • Export to Excel asks where to save, suggesting <drawing> - Tag Audit.xlsx beside the drawing. An existing file of that name is replaced.
    • Copy report puts every finding on the clipboard, tab separated.

The findings table

The export (sheet Tag Audit) and the copy have one row per offending block: duplicates first, grouped by value, then blanks, then missing.

ColumnHolds
IssueDuplicate, Blank or Missing
ValueThe shared value, for a duplicate; empty otherwise
HandleThe block reference's handle
BlockThe block name (a dynamic block's own name, not its anonymous one)
LayerThe block reference's layer
SpaceModel or the layout's name

Limitations

  • With nothing selected, every block reference in the drawing counts, and every one without the attribute (title blocks, north arrows, symbols) is listed as missing. Select the equipment first, or ignore the Missing rows, when that list is long.
  • Block references nested inside other blocks, and xref attachments, are not checked.
  • Constant attributes are not read: a block whose tag is a constant attribute is listed as missing it.
  • One attribute per run. To check two, run the tool twice.
  • The tool reports and selects; it does not renumber or fill in values.

Other uses

  • Room numbers, door numbers or panel circuit labels: any attribute that should be unique.
  • Sheet numbers in title blocks. Every layout is checked, so two sheets carrying the same number in one drawing show up as a duplicate.
  • Check that every block of one kind is labelled: select them all with Quick Select, run the audit, and the blanks are the ones still to do.
