Two tools for drawing hygiene. Drawing Cleanup runs the usual tidy-up (purge, audit, zero-length and duplicate geometry, ByLayer colour, zoom extents) from one checklist. Font and Proxy Report finds what makes a drawing look wrong on someone else's machine: objects from software this AutoCAD does not have, and text styles whose font files are missing.

What it does

Opens a checklist of six steps, runs the ticked ones in order, and reports what each one did. The checklist opens with whatever you ticked last time.

StepTicked at firstWhat it does
Purge everything unusedYes Erases unreferenced blocks, layers, linetypes, text styles, dimension styles, registered applications, multiline styles, table styles and multileader styles. It repeats until a pass finds nothing, so a block that was only used inside another unused block goes too.
Audit the drawing and fix errorsYes Queues AUDIT with fix set to Yes.
Delete zero-length lines and polylinesYes Erases lines and lightweight polylines with no length, in model space and every layout.
Delete duplicate entitiesYes Finds entities of the same type, on the same layer and in the same space, with the same geometry, and erases every copy but the first.
Set every entity colour to ByLayerNo Sets the colour of every entity in model space and the layouts, and of the attributes on block references, to ByLayer.
Zoom extentsYes Queues ZOOM Extents.

How to use it

  1. Click Drawing Cleanup, or type PYDRAWINGCLEANUP.
  2. Tick the steps you want and click OK. The choice is remembered for next time (an empty checklist is not).
  3. If a ticked step erases something (purge, zero-length, duplicates), the tool says exactly what it will delete and asks you to continue.
  4. A progress window follows the steps. Cancel stops the step that is running and skips the rest; whatever already finished stays done.
  5. A report window lists one line per step, for example: 
    Purge: 14 unused items removed
Audit: queued; it runs when this tool finishes and reports on the command line
Zero-length: 3 entities deleted
Duplicates: 12 extra copies deleted (9 groups), 2 skipped on locked layers
Zoom extents: queued
    Copy puts the report on the clipboard. A toast sums it up, such as "14 purged, 3 zero-length deleted, 12 duplicates deleted".
  6. When the tool closes, AUDIT runs and prints its findings on the command line, then the view zooms to extents.

Limitations

  • AUDIT and ZOOM do not run in checklist order: they are queued as commands of their own and run after every other step has finished. Their results are on the command line, not in the report.
  • Duplicates are judged by type, layer and geometry only. Colour, linetype, lineweight, text style and text rotation are not compared, so two lines in the same place on the same layer are duplicates even if one is red and dashed. Polylines are compared by their vertices and whether they are closed, not by arc segments or widths. Only lines, circles, arcs, lightweight polylines, text, mtext and block references are checked; a block reference's attribute values are part of its match, so two tags on one point with different values are both kept.
  • Zero-length covers lines and lightweight polylines only, not old-style 2D or 3D polylines.
  • Entities on locked layers are never erased or recoloured: the report counts them as skipped. Purge is not affected by layer locks.
  • Geometry inside block definitions is not checked for duplicates or zero length, and ByLayer does not change the colours inside block definitions. Viewports keep their colour.
  • Purge does not cover materials, visual styles, plot styles, groups or empty text. Use AutoCAD's PURGE for those.

Good to know

Every edit the tool makes itself happens inside its own command, so U takes it back. AUDIT and ZOOM are separate commands that run after it, so they come off the undo stack first: undo those two, then the cleanup itself.

The remembered checklist is stored in %APPDATA%\pyACAD\settings\cfg_pyacad_tab_cleanup_panel_drawing_cleanup_pushbutton.json. Shift+Click (or PYDRAWINGCLEANUPCFG) deletes it, so the next run opens with the default ticks again: everything but ByLayer colour.

Other uses

  • Before you issue a drawing, or before it goes to someone as an xref background.
  • Tick only Set every entity colour to ByLayer to make a consultant's background follow your layer colours.
  • Tick only Delete duplicate entities after a careless copy and paste in place.

What it does

Looks for two things that make a drawing behave differently on another machine:

  • Proxies. An object made by an application this AutoCAD does not have (its object enabler is missing). The tool finds proxy entities in model space, every layout and every block definition, and proxy objects in the drawing's named object dictionary and the dictionaries inside it. It groups them by the original class and the application that made them.
  • Missing fonts. Each text style's font file, its big font (for Asian text) and any shape file loaded for complex linetypes, looked up the way AutoCAD looks for them: the support paths, the drawing's folder and, for TrueType, the Windows fonts. Styles that come from xrefs are left out.

If it finds neither, a toast says so and that is all. Otherwise it shows the report and offers to export it or remap the fonts.

How to use it

  1. Click Font and Proxy Report, or type PYFONTANDPROXYREPORT.
  2. Read the report. It opens with counts ("3 proxy entities, 1 proxy object"), the proxy classes most common first, then each missing font as Style: file. Each list stops after 15 lines; Copy puts the report on the clipboard and the Excel export carries everything. Click OK.
  3. Choose what next: Export to Excel, Remap missing fonts (offered only when a style's own font is missing) or Done. After one choice the others are offered again, until you click Done.
  4. Export to Excel asks where to save. The name starts as <drawing> font and proxy report.xlsx. If the file exists it is replaced, not added to.
  5. Remap missing fonts asks once for the missing SHX fonts (suggesting simplex.shx) and once for the missing TrueType fonts (suggesting arial.ttf), naming the styles each answer will change. Leave the box empty or cancel to leave that kind alone. If AutoCAD cannot find the replacement either, the tool asks before using it.
  6. The remapped styles are listed in a toast, and a REGENALL is queued so the text redraws in the new font.

The Excel sheet

One sheet, Fonts and proxies, with a bold header row and one row per proxy, then one per missing font:

ColumnFor a proxyFor a missing font
IssueProxy entity or Proxy object Missing font, Missing big font or Missing shape file
NameThe original class name, or (unknown class) The text style
DetailThe application that made itThe font file
WhereThe layout (Model or its name), BLOCK:Name for a block definition, or Named objects Empty

Limitations

  • The tool reports proxies; it does not remove or explode them. The fix is the missing object enabler, or the application that made them.
  • Only a style's own font is remapped. Missing big fonts and shape files are reported and left alone.
  • A remap clears the style's TrueType typeface so the font file you typed is what counts. Bold or italic set on a TrueType style is cleared with it.
  • A style that names a font only by typeface, with no font file, is not checked.
  • Mtext that sets its own font inline keeps it; only the style changes.

Good to know

The remap happens inside the tool's own command, so Undo takes it back (the queued REGENALL is a separate command after it). The export dialog starts wherever the Save dialog last was, not necessarily in the drawing's folder.

Other uses

  • Check every drawing a consultant sends before you xref it: proxies there usually mean they work in an AutoCAD-based product you do not have.
  • Keep the Excel export with a transmittal as a record of what you received.
  • Before you send drawings out, remap company SHX fonts the recipient will not have to simplex.shx, on a copy.
