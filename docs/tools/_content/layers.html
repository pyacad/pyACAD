The Layers panel keeps layers in hand: a palette that lists them with the everyday actions one click away, a mapper that brings a drawing's layers into line with a standard from a CSV, and snapshots of which layers are on, frozen and locked that you can put back later.

What it does

Opens an AutoCAD palette titled Layer Manager that lists every layer of the active drawing, sorted by name, with whether it is current, on, frozen and locked, and its colour number. Filter the list, pick one or more layers, and act on them with the buttons underneath. It is lighter than the Layer Properties Manager and stays open beside the drawing while you work.

How to use it

  1. Click Layer Manager on the ribbon. The button stays pressed while the palette is showing; click it again to hide it. Drag the palette to dock it on the left or right, or leave it floating.
  2. Type in the Filter box to narrow the list. Plain text matches anywhere in the name, ignoring case. A term with * or ? is a wildcard pattern over the whole name (A-* means names starting with A-). Separate several terms with commas: wall, E-*.
  3. Pick layers with click, Ctrl+click and Shift+click. The status line underneath counts them and names the current layer.
  4. Click an action. Each one changes the drawing straight away, shows a toast, and re-reads the list.
  5. Double-click a row to make that layer current.

The buttons

  • Isolate: thaws and turns on the selected layers and freezes every other layer. If the current layer is not among them, the first selected layer becomes current.
  • Freeze/Thaw: freezes the selected layers, or thaws them when every one is already frozen. The current layer cannot be frozen, so it is skipped and the toast says so.
  • On/Off: turns the selected layers off, or on when every one is already off.
  • Lock/Unlock: locks the selected layers, or unlocks them when every one is already locked.
  • Set current (one layer selected): thaws it, turns it on and makes it current.
  • Merge into...: asks for a target layer name, moves everything on the selected layers onto it, then deletes them. If no layer has that name, it offers to create one (colour 7, Continuous). The toast says how many objects moved.
  • Delete: asks first, then deletes the selected layers. Layer 0, Defpoints, the current layer, xref layers and layers still in use are kept, and the toast gives the first reason; the rest are in the pyACAD log.

Good to know / limits

  • The list follows the active drawing. It is read again when the palette is shown, when the mouse comes back over it, and when you click Refresh, so a change made elsewhere shows up without you asking. Your selection and scroll position are kept when nothing changed.
  • Merge reaches everywhere in the drawing: objects inside block definitions and attributes move too, so every reference of such a block changes, and objects on locked layers are moved as well. If a selected layer cannot be deleted afterwards (layer 0, Defpoints, an xref layer), the merge fails as a whole and nothing changes.
  • Freeze, Isolate and the rest work on the layers themselves, for every viewport. They do not use viewport freeze.
  • The palette acts outside any AutoCAD command. Check how U behaves on a palette action before you rely on it for a large Merge or Delete, or take a Layer Snapshot first.
  • The Color column shows the AutoCAD colour number, not a swatch, and is not editable. Neither is any other column: rename layers and change their properties in the Layer Properties Manager or with Layer Mapper.
  • The palette is not in the Shortcuts editor. Reach it from the keyboard with its keytip: press Alt, follow the letters the ribbon shows to the pyACAD tab, then LM.
  • AutoCAD remembers the palette's size, dock side and whether it was showing. A Reload rebuilds it and clears the filter box.

Other uses

  • Focus on one discipline: filter E-*, select all the rows, Isolate.
  • Tidy an imported drawing: filter for its odd prefixes, Merge them into your own layers, then Delete what is left empty.
  • Keep it open as a live readout of which layer is current and what is frozen.

What it does

Reads a CSV that maps old layer names to new ones and brings the drawing into line. Each layer that matches a row is renamed to the new name, or merged into it when a layer of that name already exists. New names that no layer was renamed to can be created, with the colour and linetype the CSV gives. Everything planned is shown with a tick box before anything changes. The command is PYLAYERMAPPER.

The CSV

One mapping per row: old,new[,color][,linetype].

old,new,color,linetype
A-WALL*,A-WALL,1,
E-LITE,E-LIGHTING,yellow,
OLD-HIDDEN,M-HIDDEN,4,HIDDEN
  • old may use * (any run of characters) and ? (one character), matched against the whole name, ignoring case. Each layer takes the first row that fits it, so put specific rows above general ones.
  • new is the standard name.
  • color, optional, is a colour number from 1 to 255 or one of red, yellow, green, cyan, blue, magenta, white (black means 7 too).
  • linetype, optional, must already be loaded in the drawing.
  • Any columns after the fourth, such as a notes column, are ignored. Blank lines are skipped, and so is a first row that reads like a header (old,new, from,to, existing,standard and the like).
  • Cells may be separated by commas, semicolons or tabs, whichever the first row uses, and may be quoted. Excel's CSV, CSV UTF-8 and Unicode text files all read.

How to use it

  1. Click Layer Mapper (or type PYLAYERMAPPER) and pick the CSV.
  2. If the standard names layers the drawing does not have, it lists them (with the colour and linetype each would get) and asks whether to create them too.
  3. A checklist shows every step, all ticked: Rename A to B, Merge A into B, Create B (color 3, DASHED). Layers that will be left alone are named above the list. Untick anything that should not change, then confirm.
  4. The steps run in plan order. A toast sums up what was renamed, merged (and how many objects moved) and created. Steps that failed are counted in the toast and listed in the pyACAD log.

How the plan is made

  • A layer is renamed when no layer has the new name yet. When several layers map to the same new name (A-WALL* above), the first is renamed and the rest are merged into it.
  • A layer is merged when a layer with the new name already exists: everything on it moves across, including objects inside blocks, and the old layer is deleted.
  • A layer already called the new name is left as it is. A name that differs only in case is renamed, so the case comes into line.
  • Layer 0, Defpoints, xref layers and new names AutoCAD would refuse (with characters such as < > / \ : ; ? * | , =) are skipped, with the reason.

Good to know / limits

  • The colour and linetype in the CSV are used only for layers it creates. A layer that is renamed or merged keeps its own colour and linetype.
  • A created layer with no colour in the CSV gets colour 7, and one with no linetype gets Continuous. A linetype that is not loaded makes that create step fail; load it first.
  • Unticking a rename that a later merge depends on makes the merge fail (its target does not exist); it is reported, the rest still run.
  • The whole run is one AutoCAD command, so U takes it back.

Other uses

  • Bring a consultant's drawing onto your office standard before you xref it.
  • Collapse a drawing's dozens of near-duplicate layers (WALL, Walls, wall-new) into one with a few wildcard rows.
  • Keep one CSV per client standard and run the matching one on every drawing that comes in.

What it does

Takes a snapshot of every layer's on, frozen and locked state and saves it under a name, so you can switch layers around freely and come back. Restoring sets those three things back on every layer the snapshot knows. The command is PYLAYERSNAPSHOT; Shift+Click is PYLAYERSNAPSHOTCFG.

How to use it

  1. Click Layer Snapshot and choose Save, Restore or Delete.
  2. Save: type a name (the date and time is filled in). A name already used for this drawing, in any case, asks before it is replaced.
  3. Restore: pick a saved state from the list, newest first, each with when it was saved and how many layers it holds. The toast says how many layers changed and how many saved layers the drawing no longer has.
  4. Delete: tick one or more saved states and confirm.
  5. Shift+Click lists this drawing's saved states without changing anything, with a Copy button.

Good to know / limits

  • Only on, frozen and locked are restored. Colour, linetype and the rest are saved in the snapshot but never put back.
  • Layers created after the snapshot are left as they are. Layers deleted since are skipped.
  • The current layer is never frozen by a restore.
  • The states are not stored in the drawing. They live in a file under %APPDATA%\pyACAD\data, keyed by the drawing's full path. So they are yours alone, they do not travel with the DWG, and moving or renaming the drawing leaves them behind. Every drawing that has never been saved shares one set.
  • A restore is one AutoCAD command, so U takes it back.
  • AutoCAD's own Layer States (LAYERSTATE) are stored in the drawing and can restore more properties. Use them when the state must travel with the file; use this when you want a quick personal bookmark.

Other uses

  • Save before you Isolate in the Layer Manager, and restore to get every layer back exactly as it was.
  • Keep a "plot" and a "work" state for a drawing and switch between them in two clicks.
